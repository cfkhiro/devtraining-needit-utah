**これから私たちは、**（Xaquinel、2024年）
- 全員の「やりたいこと」をカードで見つける協力ゲーム。2〜8人、約15分
- ふだん言い出せないことを、ゲームを口実に提案できる
- 班では：10/27の投票で星3。この方向性で進めることになった
- 出典：https://www.xaquinel.com/works/korekara-watashitachi-wa

**どこかにマイル**（JAL、2016年〜）
- 候補の中から行き先がシステムで決まる国内線の特典航空券。必要マイル数は資料で食い違い（6,000／往復7,000）。使う前にJAL公式で確認
- 受賞：2018年度グッドデザイン賞
- 出典：https://press.jal.co.jp/ja/release/201810/004908.html

**どこかにビューーン!**（JR東日本）
- JRE POINTで、4つの候補駅からランダムに1つに決まる新幹線の往復旅。最大4名
- 出典：https://www.watch.impress.co.jp/docs/news/2057388.html

**Timeleft**
- アプリで性格診断に答えると、知らない人とグループを組まされ、店も指定されて一緒に食事する。東京でも開催
- 出典：https://timeleft.com/jp/

**問題の裏づけ**
- 口コミがない店や少ない店を候補から外したことがある人は約77%（子どもがいる20〜40代360人の調査）。出典：Forbes JAPAN（2026年5月）https://forbesjapan.com/articles/detail/97252 （出典を開き直していない。要確認）
- 「レコメンドが人気店ばかりを勧める」こと自体を直した一般向けサービスは見つからなかった。既存の解決は「ランダムにする」か「空きを見せる」のどちらかで、「自分に合うのに知られていないものに出会わせる仕組み」はまだ空いている（Claudeの読み）

**文化・遊びとのつながり**（Claudeの整理）
- 決める責任を運や人に預ける仕組み：あみだくじ、じゃんけん、おまかせコース、おみくじ

### 2-6-4. 読み取り（Claude）
- 2つの事例表の結論は、どちらも「自分から一歩を踏み出せない人」がこぼれる、で一致している。中心人物の「自分一人では決めない」とつながる
- 中心人物に近いのは「選択を委ねる」型（どこかにマイル、47都道府県ルーレット、Pack Up + Go、一万円選書）と「これから私たちは、」。ただし、47都道府県ルーレットとPack Up + Goは一人でも使える。みんなで決める形に寄せるなら、その場の全員が回す・引くことで結果がみんなのものになる点を見る
- 「情報を隠す」型（文庫X、Pack Up + Go）は、外れても「隠されていたから」と言えるので、選んだ人の責任を軽くする仕掛けとしても読める
- ハグドラムは「2人1組で合わせる」ので、違いのある人どうしが一緒に遊ぶ形になっている。中心人物の「みんなで」とつなげやすい
- 良いインクルーシブ事例（Bubble Braille、Art of Fauna）は、障害のある人「だけ」の道具にせず、障害のない人も一緒に夢中になれる遊びにしている

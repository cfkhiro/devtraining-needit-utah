デザイン思考講座の班で、製品アイデアの根拠になる調査・研究を探しています。次の条件で探してください。

## 背景（短く）
- 中心人物：友人や仲間と集まるとき、行き先や遊びが「いつもの」（飲み会・食事）になりがちで、本当は違うことをしたいのに、自分が言い出して外すのが怖くて言えない人
- 製品の方向：誰か一人が言い出さなくても、くじや札で行き先が決まり、いつもと違う体験に出会える仕組み
- 知りたいのは「このニーズが、班員の主観ではなく、世の中に本当にあるか」

## 探してほしいテーマ（優先順）
1. 友人・仲間との遊びや集まりが「いつも同じ」「マンネリ」になっていることへの不満の有無と割合
2. グループで行き先や店を決めるとき、誰が決めているか／決めるのが負担か／幹事や言い出す役の負担
3. 本当は希望があるのに言わない・言いづらい経験（遠慮、外したくない、場の空気）
4. 行き先を他人や運に任せる商品・サービス（ミステリーツアー、旅くじ、どこかにマイル等）を使う理由。特に「安いから」と「行き先が分からない楽しさ」を分けて聞いたもの
5. お酒を飲まない人・夜に出にくい人（子育て・介護等）が、友人の集まりに参加しにくいと感じているか
6. 友人と会うことへの疲れ・負担、会う頻度の変化

## 探し方の条件
- 日本の調査を優先。なければ海外でも可（国を明記）
- 2022年以降を優先。古いものは年を明記して可
- 調査会社・企業のプレスリリース、官公庁の統計、学術論文のどれでも可
- 1テーマにつき2〜3件。見つからないテーマは「見つからなかった」と書く。近い調査で無理に埋めない

## 1件ごとに書いてほしいこと（この形で）
```
【調査名・実施主体】例：Honda「大人の友だち付き合い調査」
【時期】実施時期（分かれば発表日も）
【対象・人数】例：全国の20〜30代の働く男女800人、インターネット調査
【使える数字】設問の文と割合をそのまま。例：「社会人になって友だちと遊ぶときにすること」食事65.5%、飲み47.3%
【測っていないこと】このテーマに対して、その調査が直接は聞いていないこと。例：「マンネリ」「いつも同じ」の設問はない
【注意】企業の販促調査か、対象が偏っているか、数字が出典どうしで食い違うか、原文を開けたか
【URL】一次情報（プレスリリース・論文）のURL。記事しかなければ記事のURLと「一次情報は未確認」
```

## 守ってほしいこと
- **原文（一次情報）を開けたかどうかを、1件ごとに必ず書く**。検索結果の要約だけで書いた場合は「要約のみ・原文未確認」と明記
- 数字を推測で補わない。設問の文が分からなければ「設問文は未確認」と書く
- 同じ調査の数字が記事によって違う場合は、両方の数字と出典を並べる
- 自社サービスの宣伝のための調査（例：サービス運営会社が自社の領域について行った調査）は、その旨を【注意】に書く
- 「ニーズがある」と結論づけない。何が言えて、何が言えないかを分けて書く

## 最後にまとめてほしいこと
- テーマ1〜6それぞれについて、「言えること」「言えないこと（調査が見つからない・測られていない）」を2〜3行で
- 原文確認が必要なものの一覧
